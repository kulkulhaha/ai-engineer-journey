## 손계산 예제 (재풀이용 — 답은 가리고 풀 것)

```
X = [[3, 4], [1, 3], [2, 2]]    n = 3, d = 2
```

```
μ  = (2, 3)
X_c = [[1, 1], [−1, 0], [0, −1]]
C  = X_cᵀX_c / (n−1) = [[1, ½], [½, 1]]
λ₁ = 3/2,  λ₂ = 1/2
v₁ = (1, 1)/√2,  v₂ = (1, −1)/√2
Z₁ = X_c v₁ = [2, −1, −1]/√2   →  Var(Z₁) = 3/2 = λ₁ ✓
Z₂ = X_c v₂ = [0, −1, 1]/√2    →  Z₁·Z₂ = 0 (점수 무상관)
```
