# 논문 리뷰 기록 템플릿

목적: abstract를 요약/복사하는 게 아니라, 읽은 내용을 자기 언어로 재구성해서 실제로 이해했는지 스스로 확인하는 것.
매 논문마다 이 템플릿으로 한 장씩 기록 (레포에 `papers/논문제목.md` 형태로 쌓는 걸 추천 — week01 폴더처럼 나중에 검색/회고 가능).

```md
# [논문 제목]

- 저자 / 연도 / 링크:
- 읽은 날짜:
- 왜 이 논문을 골랐나 (로드맵/현재 공부 중인 개념과의 연결):

## 한 문장 요약 (내 언어로, abstract 그대로 옮기지 않기)


## 핵심 아이디어 / 기여
(수식이나 구조를 그대로 베끼지 말고, "이 논문이 푸는 문제 → 기존 방법의 한계 → 이 논문의 접근" 순서로 스스로 설명)


## 이해 안 된 부분 / 다시 봐야 할 부분
(막히는 지점을 구체적으로 — "3장 전체가 어렵다"보다 "3.2절의 손실함수 왜 저렇게 정의되는지"처럼)


## 비판적으로 볼 점
- 이 방법의 한계나 가정은 무엇인가
- 실무/프로젝트에 적용한다면 어떤 문제가 생길 수 있는가
- 대안이 될 만한 다른 접근이 있는가

## 실습으로 연결
(코드로 직접 재현/검증해볼 만한 부분이 있다면 무엇을, 어떻게)

## 관련 개념 / 다음에 읽을 논문
```

**기록 위치 관련 팁:** 논문 제목이나 방법론 이름으로 파일명을 짓고, `papers/README.md`에 인덱스(제목 – 한 줄 요약 – 링크)를 만들어두면 나중에 "어떤 논문에서 이 얘기 봤더라" 할 때 빠르게 찾을 수 있음.
